Álgebra

10 preguntas
01

Uno de los factores de 27(x + 2)³ − 64, es:

Resolución. Es una diferencia de cubos: 27(x+2)³ − 64 = [3(x+2)]³ − 4³. Con a = 3(x+2) = 3x+6 y b = 4: a³−b³ = (a−b)(a²+ab+b²). El factor (a−b) = (3x+6) − 4 = 3x+2. Clave: B
02

La expresión equivalente a: b² + c² − a² − d² − 2ad + 2bc, es:

Resolución. Se agrupa para formar diferencia de cuadrados: (b² + 2bc + c²) − (a² + 2ad + d²) = (b+c)² − (a+d)² = [(b+c)+(a+d)]·[(b+c)−(a+d)] = (b+c+a+d)(b+c−a−d). Clave: C
03

La suma de los factores primos del polinomio P(x) = x³ − 7x − 6, es:

Resolución. Por divisores binómicos: P(−1) = −1+7−6 = 0, P(−2) = −8+14−6 = 0, P(3) = 27−21−6 = 0. Luego P(x) = (x+1)(x+2)(x−3). Suma de factores primos = (x+1)+(x+2)+(x−3) = 3x. Clave: B
04

El número de factores primos del polinomio P(x) = x⁴ − 5x² + 4, es:

Resolución. Aspa simple en x²: x⁴ − 5x² + 4 = (x² − 1)(x² − 4). Cada una es diferencia de cuadrados: (x−1)(x+1)(x−2)(x+2). Son 4 factores primos. Clave: C
05

Luego de factorizar S(x) = 18x³ + 9x² − 2x − 1, uno de sus factores primos es:

Resolución. Agrupando: 9x²(2x+1) − 1(2x+1) = (2x+1)(9x²−1) = (2x+1)(3x−1)(3x+1). Un factor primo es 3x−1. Clave: D
06

Luego de racionalizar E = a / ⁷√(x³ y⁴ z²), el denominador de la expresión final es:

Resolución. Se multiplica numerador y denominador por ⁷√(x⁴ y³ z⁵) para completar exponentes a 7: ⁷√(x³·x⁴ · y⁴·y³ · z²·z⁵) = ⁷√(x⁷ y⁷ z⁷) = xyz. Clave: B
07

El denominador racionalizado de la expresión V = (x − 4) / (x − 3√x + 2) ; x > 0, es:

Resolución. Factorizando con u = √x: denominador x − 3√x + 2 = (√x − 1)(√x − 2) y numerador x − 4 = (√x − 2)(√x + 2). Se simplifica (√x − 2): V = (√x + 2)/(√x − 1). Al racionalizar (×(√x + 1)) el denominador queda (√x − 1)(√x + 1) = x − 1. Clave: C
08

Si x₁ y x₂ son las raíces de la ecuación 2x² − 8x + 5 = 0, el valor de (1/x₁ + 1/x₂) es:

Resolución. Por Cardano-Vieta: x₁+x₂ = 8/2 = 4 ; x₁·x₂ = 5/2. Entonces 1/x₁ + 1/x₂ = (x₁+x₂)/(x₁·x₂) = 4 ÷ (5/2) = 8/5. Clave: B
09

El valor de "x" en la ecuación (x + 1) + (x + 2) + (x + 3) + … + (x + n) = n², es:

Resolución. Hay n términos: nx + (1+2+…+n) = n² → nx + n(n+1)/2 = n². Dividiendo entre n: x + (n+1)/2 = n → x = n − (n+1)/2 = (2n − n − 1)/2 = (n − 1)/2. Clave: B
10

El número de valores enteros que satisfacen el sistema 3x − 7 < x + 5 < 2x + 9, es:

Resolución. Se separan: 3x−7 < x+5 → 2x < 12 → x < 6. Y x+5 < 2x+9 → −4 < x. Entonces −4 < x < 6. Enteros: −3, −2, −1, 0, 1, 2, 3, 4, 5 → 9 valores. Clave: C

Aritmética

10 preguntas
11

En una progresión aritmética, a₃ = 1 y a₇ = −7. Calcular la suma de los 15 primeros términos.

Resolución. r = (a₇ − a₃)/(7−3) = (−7 − 1)/4 = −2. a₁ = a₃ − 2r = 1 − 2(−2) = 5. S₁₅ = (15/2)[2(5) + 14(−2)] = (15/2)(10 − 28) = (15/2)(−18) = −135. Clave: B
12

En una progresión geométrica a₁ = 5 y a₄ = 40. Calcular la suma de los seis primeros términos.

Resolución. r³ = a₄/a₁ = 40/5 = 8 → r = 2. S₆ = a₁(r⁶ − 1)/(r − 1) = 5(64 − 1)/(2 − 1) = 5·63 = 315. Clave: C
13

Calcular el valor de la sumatoria Σ (desde k=1 hasta 20) de (3k + 2).

Resolución. Σ(3k+2) = 3·Σk + Σ2 = 3·[20·21/2] + 2·20 = 3·210 + 40 = 630 + 40 = 670. Clave: C
14

Un número de dos cifras tiene como suma de cifras 11. Si se intercambian sus cifras, el nuevo número excede en 45 al número original. Hallar dicho número.

Resolución. Número = 10a + b, con a + b = 11. Invertido: 10b + a = (10a + b) + 45 → 9b − 9a = 45 → b − a = 5. Con a + b = 11: b = 8, a = 3. El número es 38 (verificación: 83 − 38 = 45). Clave: B
15

Al convertir el número 365 (base 10) al sistema de base 7, la suma de sus cifras es:

Resolución. Divisiones sucesivas entre 7: 365 = 7·52 + 1 ; 52 = 7·7 + 3 ; 7 = 7·1 + 0 ; 1 = 7·0 + 1. Leyendo residuos: 365 = 1031₇. Suma de cifras = 1 + 0 + 3 + 1 = 5. Clave: C
16

El numeral de cifras máximas de tres cifras del sistema de base "n", expresado en base 10, es 124. Hallar "n".

Resolución. El numeral de cifras máximas de 3 cifras en base n equivale a n³ − 1. Entonces n³ − 1 = 124 → n³ = 125 → n = 5. Clave: B
17

¿Cuál es el valor de "a" si el numeral 2a41 es divisible por 11?

Resolución. Criterio del 11 (suma alternada desde la derecha): 1 − 4 + a − 2 = a − 5, múltiplo de 11 → a − 5 = 0 → a = 5 (verificación: 2541 = 11·231). Clave: B
18

¿Cuántos números de dos cifras, al dividirse entre 7 dan residuo 2 y al dividirse entre 4 dan residuo 1?

Resolución. N = 7k + 2. Imponiendo N ≡ 1 (mód 4): 7k + 2 ≡ 1 → 3k ≡ 3 → k ≡ 1 (mód 4). Para k = 5, 9, 13 se obtienen los de dos cifras: 37, 65, 93 → 3 números. Clave: D
19

¿Cuántos divisores tiene el número 3600?

Resolución. Descomposición canónica: 3600 = 2⁴ · 3² · 5². Cantidad de divisores = (4+1)(2+1)(2+1) = 5·3·3 = 45. Clave: C
20

La suma de todos los divisores del número 240 es:

Resolución. 240 = 2⁴ · 3 · 5. Suma de divisores = [(2⁵−1)/(2−1)]·[(3²−1)/(3−1)]·[(5²−1)/(5−1)] = 31 · 4 · 6 = 744. Clave: A

Competencia Comunicativa

10 preguntas
21

Según su acentuación, las palabras reloj, compás y reunión son:

Resolución. En las tres la mayor fuerza de voz recae en la última sílaba: re-loj, com-pás, re-u-nión. Las palabras acentuadas en la última sílaba se llaman agudas u oxítonas. Clave: B
22

La serie que presenta únicamente palabras graves (llanas), es:

Resolución. Graves = acento en la penúltima sílaba. ár-bol, lá-piz, cés-ped son las tres graves. En (a) y (d) son agudas, en (c) esdrújulas, y (e) mezcla grave + agudas. Clave: B
23

La oración que presenta tildación correcta, es:

Resolución. En (d): Dé lleva tilde diacrítica (verbo dar) y algún es aguda terminada en "n". Las demás omiten tildes obligatorias: tí­pica, Á­gilmente/césped, rá­pido/capi­tán, japo­nés. Clave: D
24

La expresión con uso correcto de las letras mayúsculas, es:

Resolución. "río" es nombre común (minúscula), "Amazonas" y "Perú" son propios (mayúscula) y la oración inicia con mayúscula. Solo (c) cumple todo. Clave: C
25

El enunciado que presenta uso correcto de las letras mayúsculas, es:

Resolución. El nombre propio de una institución lleva mayúscula en todas sus palabras significativas: Universidad Nacional San Antonio Abad. En las demás hay errores (nacional, cusco, puno en minúscula; o Lago/Museo genéricos en mayúscula; "Historia del Perú" como título). Clave: B
26

En la expresión «Unos cantaban; otros, bailaban», la coma empleada es:

Resolución. La coma después de "otros" reemplaza al verbo omitido ("cantaban"/"bailaban"). La coma que sustituye un verbo elidido se llama coma elíptica. Clave: C
27

En el enunciado «Ana estudia Medicina ___ su hermano, Derecho», el signo de puntuación que se ha omitido es:

Resolución. Se separan dos proposiciones coordinadas y la segunda ya contiene una coma (elíptica). En ese caso corresponde el punto y coma: «Ana estudia Medicina; su hermano, Derecho». Clave: C
28

La expresión que presenta paréntesis en acotación de los personajes en obras teatrales, es:

Resolución. En las obras teatrales, el paréntesis encierra las acotaciones (indicaciones de acción o gesto del personaje). Eso ocurre en (e): (Acercándose lentamente a Romeo). Clave: E
29

Las palabras belleza, justicia y esperanza son sustantivos:

Resolución. Designan realidades no perceptibles por los sentidos (cualidades, ideas, sentimientos); por ello son sustantivos abstractos. Clave: B
30

Las palabras jauría, enjambre, arboleda y constelación son sustantivos:

Resolución. En singular nombran un conjunto: jauría (perros), enjambre (abejas), arboleda (árboles), constelación (estrellas). Son sustantivos colectivos. Clave: C

Física

10 preguntas
31

Sobre un cuerpo actúan las fuerzas F₁ = (5î − 2ĵ) N, F₂ = (−2î + 6ĵ) N y F₃. Si el cuerpo se mueve con rapidez constante (equilibrio), el módulo de F₃, en N, es:

Resolución. En equilibrio ΣF = 0 → F₃ = −(F₁ + F₂) = −[(5−2)î + (−2+6)ĵ] = −(3î + 4ĵ). Módulo = √(3² + 4²) = √25 = 5 N. Clave: C
32

En la figura, calcular el módulo del momento resultante de las fuerzas respecto al punto A, en N·m.

Resolución. Momento = fuerza × brazo perpendicular. La fuerza de 50 N (horizontal, a 4 m de altura) gira en un sentido: 50·4 = 200. Las de 20 N (a 2 m) y 30 N (a 3 m) giran en sentido contrario: 20·2 = 40 y 30·3 = 90. Resultante = 200 − 40 − 90 = 70 N·m. Clave: D
33

Un bloque de 2 kg es lanzado sobre una superficie rugosa con una rapidez de 10 m/s. Determinar su rapidez, en m/s, cuando ha disipado 75 J por fricción.

Resolución. Energía cinética inicial = ½·2·10² = 100 J. Al disipar 75 J queda EC = 100 − 75 = 25 J. Entonces ½·2·v² = 25 → v² = 25 → v = 5 m/s. Clave: B
34

Un bloque de 60 N se desplaza por acción de una fuerza horizontal F = 40 N. El coeficiente de rozamiento cinético entre el bloque y el piso es 0,25. Determinar el trabajo realizado por "F" al cabo de 3 s, si parte del reposo. (g = 10 m/s²)

Resolución. Masa m = 60/10 = 6 kg. Fricción f = 0,25·60 = 15 N. Fuerza neta = 40 − 15 = 25 N → a = 25/6 m/s². Distancia en 3 s desde el reposo: d = ½·(25/6)·3² = 225/12 = 18,75 m. Trabajo de F = 40·18,75 = 750 J. Clave: C
35

Determine el impulso resultante, en N·s, sobre un bloque de 2 kg desde t = 0 hasta t = 4 s, según la gráfica F vs t mostrada (superficie lisa).

Resolución. El impulso es el área bajo la gráfica F–t. Es un triángulo de base 4 s y altura 40 N: I = ½·(4)·(40) = 80 N·s. Clave: D
36

Una esfera de 2 kg impacta frontalmente con una pared a 20 m/s y rebota con 10 m/s. Si estuvo en contacto con la pared 0,05 s, determinar el módulo de la fuerza media que ejerce la pared sobre la esfera, en N.

Resolución. Tomando positivo el sentido de rebote: Δp = m(v_f − v_i) = 2[10 − (−20)] = 2·30 = 60 kg·m/s. Fuerza media = |Δp|/t = 60/0,05 = 1200 N. Clave: C
37

Las esferas A y B, de igual masa, se mueven como indica la figura. Si luego del choque la esfera B queda en reposo, determinar la rapidez que adquiere A, en m/s. (superficie lisa)

Resolución. Conservación de la cantidad de movimiento (masas iguales m). Tomando la derecha como positiva: m(10) + m(−20) = m·v_A + m·0 → 10 − 20 = v_A → v_A = −10. La rapidez es 10 m/s (A se mueve hacia la izquierda). Clave: B
38

Una partícula realiza un MAS. Si su rapidez máxima es 8 m/s y su amplitud es 2 m, el periodo de oscilación, en segundos, es:

Resolución. La rapidez máxima en MAS es v_máx = ω·A → ω = v_máx/A = 8/2 = 4 rad/s. Periodo T = 2π/ω = 2π/4 = π/2 s. Clave: A
39

Determine la presión hidrostática, en Pa, en el fondo de un tanque que contiene agua hasta una altura de 2,5 m. (ρ_agua = 1000 kg/m³ ; g = 10 m/s²)

Resolución. Presión hidrostática P = ρ·g·h = 1000·10·2,5 = 25 000 Pa = 2,5×10⁴ Pa. Clave: C
40

Un tanque muy ancho contiene agua. Por un orificio ubicado a 3,2 m por debajo de la superficie libre sale un chorro. Calcular la rapidez de salida del agua, en m/s. (g = 10 m/s²)

Resolución. Por el teorema de Torricelli, v = √(2gh) = √(2·10·3,2) = √64 = 8 m/s. Clave: B

Geometría

10 preguntas
41

En un triángulo ABC se traza la bisectriz interior BP (P en AC). Si AB = 6, BC = 9 y AC = 10, el valor de AP es:

Resolución. Teorema de la bisectriz interior: AP/PC = AB/BC = 6/9 = 2/3. Como AP + PC = 10, AP = (2/5)·10 = 4. Clave: C
42

En un triángulo rectángulo ABC, recto en B, se traza la altura BH relativa a la hipotenusa. Si AH = 4 y HC = 9, el valor de BH es:

Resolución. Por el teorema de la altura (relaciones métricas en el triángulo rectángulo): BH² = AH·HC = 4·9 = 36 → BH = 6. Clave: B
43

Los lados de un triángulo miden 5, 7 y 8. La longitud de la mediana relativa al lado que mide 8, es:

Resolución. Teorema de la mediana: 4·m² = 2b² + 2c² − a², con a = 8 el lado al que es relativa y b = 5, c = 7. 4m² = 2(25) + 2(49) − 64 = 50 + 98 − 64 = 84 → m² = 21 → m = √21. Clave: A
44

En un triángulo ABC se traza la base media MN paralela al lado AC (M punto medio de AB y N punto medio de BC). Si la altura relativa al lado AC mide 12, la distancia del vértice B a la recta MN es:

Resolución. La base media MN pasa por los puntos medios, de modo que corta la altura justo a la mitad. La distancia del vértice B a MN es la mitad de la altura: 12/2 = 6. Clave: C
45

En un trapecio, las bases miden 6 y 14. La longitud del segmento que une los puntos medios de las diagonales, es:

Resolución. En todo trapecio, el segmento que une los puntos medios de las diagonales es igual a la semidiferencia de las bases: (B − b)/2 = (14 − 6)/2 = 4. Clave: B
46

En un trapecio, la base menor mide 8 y la mediana mide 11. La base mayor mide:

Resolución. La mediana del trapecio es el promedio de las bases: m = (B + b)/2 → 11 = (B + 8)/2 → B + 8 = 22 → B = 14. Clave: D
47

En una semicircunferencia de diámetro AB, se ubica el punto C. Si el arco AC mide 70°, la medida del ángulo ABC es:

Resolución. El ángulo ABC es inscrito y subtiende el arco AC. Su medida es la mitad del arco: 70°/2 = 35°. Clave: A
48

En un triángulo rectángulo los catetos miden 6 y 8. El radio de la circunferencia inscrita es:

Resolución. La hipotenusa es c = √(6² + 8²) = 10. En un triángulo rectángulo el inradio es r = (cateto + cateto − hipotenusa)/2 = (6 + 8 − 10)/2 = 2. Clave: B
49

El ángulo interior de un polígono regular mide 150°. El número de diagonales de dicho polígono es:

Resolución. El ángulo exterior mide 180° − 150° = 30°, luego el número de lados es n = 360°/30° = 12. Número de diagonales = n(n − 3)/2 = 12·9/2 = 54. Clave: C
50

El número total de diagonales de un polígono convexo es el triple de su número de lados. ¿Cuántos lados tiene el polígono?

Resolución. n(n − 3)/2 = 3n. Multiplicando por 2: n(n − 3) = 6n → n − 3 = 6 → n = 9. Clave: A

10 preguntas
51

La fórmula correcta del sulfato de cromo (III) es:

Resolución. El cromo (III) es Cr³⁺ y el ion sulfato es SO₄²⁻. Se intercambian cargas: Cr₂(SO₄)₃. Cr₂(SO₄)₃. Clave: B
52

El nombre correcto del compuesto Fe₂(SO₄)₃ es:

Resolución. El anión es sulfato (SO₄²⁻). Tres sulfatos aportan −6, repartido entre dos hierros → cada Fe es +3. Entonces es sulfato de hierro (III). Clave: C
53

El número de oxidación del cromo en el dicromato de potasio K₂Cr₂O₇, es:

Resolución. K: +1 (×2 = +2); O: −2 (×7 = −14). La molécula es neutra: 2 + 2·(E.O. del Cr) − 14 = 0 → 2·Cr = 12 → Cr = +6. Clave: B
54

Respecto a los compuestos inorgánicos, marque la proposición correcta:

Resolución. En H₂SO₄: H = +1 (×2 = +2), O = −2 (×4 = −8); neutro: 2 + S − 8 = 0 → S = +6. Las demás son falsas (CO₂ no es peróxido, el Na es +1, el óxido de calcio es CaO, el agua es un óxido/hidruro no metálico). Clave: A
55

¿Cuántas moléculas hay en 1,5 mol de dióxido de carbono (CO₂)? (N_A = 6,02×10²³)

Resolución. N° de moléculas = n·N_A = 1,5 · 6,02×10²³ = 9,03×10²³ moléculas. Clave: C
56

La masa, en gramos, de 3 moles de carbonato de calcio (CaCO₃) es: (masas atómicas: Ca = 40, C = 12, O = 16)

Resolución. Masa molar de CaCO₃ = 40 + 12 + 3·16 = 100 g/mol. Masa = n·M = 3·100 = 300 g. Clave: A
57

Un litro de una sustancia gaseosa a condiciones normales tiene una masa de 1,25 g. Su masa molar, en g/mol, es: (1 mol de gas ocupa 22,4 L a C.N.)

Resolución. La masa molar = masa de 22,4 L a C.N. Si 1 L pesa 1,25 g, entonces M = 1,25 g/L · 22,4 L/mol = 28 g/mol. Clave: D
58

Una sustancia contiene 40% de carbono, 6,67% de hidrógeno y 53,33% de oxígeno. Su fórmula empírica es: (masas atómicas: C = 12, H = 1, O = 16)

Resolución. Moles (en 100 g): C = 40/12 = 3,33 ; H = 6,67/1 = 6,67 ; O = 53,33/16 = 3,33. Dividiendo entre el menor (3,33): C = 1, H = 2, O = 1 → CH₂O. Clave: B
59

¿Cuántos litros de oxígeno, a condiciones normales, se obtienen al descomponer 245 g de clorato de potasio según 2KClO₃ → 2KCl + 3O₂? (masas atómicas: K = 39, Cl = 35,5, O = 16)

Resolución. M(KClO₃) = 39 + 35,5 + 3·16 = 122,5 g/mol → moles de KClO₃ = 245/122,5 = 2 mol. Por la relación 2:3, moles de O₂ = (3/2)·2 = 3 mol. Volumen a C.N. = 3·22,4 = 67,2 L. Clave: C
60

La reacción química Zn(s) + 2HCl(ac) → ZnCl₂(ac) + H₂(g), según el agrupamiento atómico, se clasifica como:

Resolución. Un elemento libre (Zn) desplaza a otro elemento (H) de su compuesto (HCl), liberándolo como H₂. Por el agrupamiento atómico es una reacción de desplazamiento simple. Clave: D
